# 🗄️⚙️ MongoDB Seeder

Database seeding script written in JavaScript using Faker.js to generate large volumes of realistic fake data for testing and master’s dissertation development.

## 📂 Repository Structure

The repository is organized as follows:

- `/mongodb-seeder/models`: Folder contains all the models necessary for application.
- `/mongodb-seeder/seederDB.js`: Js script that seeds fake data into mongo database
